
# 律析 LawFlow

律析 LawFlow 是一个本地优先的法律材料学习与专业表达工作台。

它面向律师、企业法务与法律内容团队，帮助用户把法规、新闻、判决、尽调材料或内部笔记，整理为可确认的章节结构、可审阅的讲稿、可导出的 `Word` 文档，以及可收听的音频内容。

LawFlow 不替代律师形成正式法律意见。所有生成结果都应经过人工审核后，再用于学习、培训、客户沟通或公开表达。

## 产品定位

LawFlow 重点解决两类高频问题：

- 学习效率不足：材料太长、太散、术语密集，难以在碎片时间完成系统阅读；
- 表达准备低效：手头已有资料，但难以快速整理成培训讲稿、分享稿、播客稿或客户可读内容。

它不是通用写作工具，而是围绕法律材料整理、知识转译、人工审阅与音频输出设计的专业工作流。

## 适用场景

- 晨间 / 晚间法律速听：把单篇资讯提炼为适合碎片时间收听的短稿；
- 专题学习：围绕一份或多份材料生成分章节学习内容；
- 客户培训 / Speak Note：形成可讲、可改、可导出的培训讲稿；
- 法律科普播客：把实务热点和经验积累整理为适合对外传播的讲稿。

## 核心能力

- 本地项目空间：按专题、客户或案件管理材料与输出物；
- 材料导入：支持 `DOCX`、`TXT`、`Markdown` 和粘贴文本；
- 公开来源发现：可选检索公开网页，并由用户逐条确认导入；
- 材料地图：展示目录结构、主题信号、规范名称与候选核验点；
- 内容结构规划：先生成章节方案，再人工确认，再进入正文生成；
- 写作画像：支持内置画像、自定义画像、播客转写提取，以及 `Markdown` 导入导出；
- 章节级生产：支持单节重写、单节导出，避免整篇返工；
- 音频工作流：支持生成口播脚本、试听、合成 `MP3`、导出音频；
- 成果导出：支持导出 `Markdown`、`DOCX`、任务表、证据映射和审计摘要。

## 推荐工作流

1. 新建项目：选择学习或表达场景；
2. 导入材料：上传文件、粘贴文本，或按主题发现公开来源；
3. 查看材料地图：先理解结构、主题与待核验点；
4. 确认章节方案：先定结构，再进入正文生成；
5. 生成讲稿：按所选画像和场景规则生成可审阅内容；
6. 局部修改：可单独重做某一节，或在线修订整篇；
7. 生成音频脚本：用于通勤学习、培训预演或播客录制；
8. 导出成果：按场景导出 `Word`、`Markdown`、音频与项目证据。

## 当前版本特点

- 本地优先：项目数据、材料与导出结果默认保存在本机；
- 双路径生成：既支持配置外部模型 API，也支持把材料包交给 ChatGPT / Agent 生成后回写审阅；
- 安全边界明确：公开网页检索默认只用于发现候选来源，不自动混入正文；
- 轻量部署：首版不强制引入独立向量库或额外检索服务。

## 模型与音频配置

### 文本生成

支持以下模型接入方式：

- `OpenAI`；
- `DeepSeek`；
- 兼容 OpenAI 协议的企业网关或其他模型服务。

### 音频合成

支持以下音频方案：

- macOS 本地语音；
- `Edge TTS`；
- 兼容 `/audio/speech` 的接口；
- `MiniMax` 原生接口。

### 播客风格提取

支持以下画像来源：

- 直接粘贴播客转写文本；
- 调用兼容 `/audio/transcriptions` 的服务转写音频片段；
- 导入已有画像 `Markdown` 文件。

## 导出与交付

LawFlow 当前支持两类主要交付风格：

- 法律工作底稿：适合内部审阅与继续修改；
- 播客讲稿：适合朗读、录音和对外传播。

播客讲稿模板当前已支持：

- 宋体 11 号；
- 1.3 倍行距；
- 首行缩进；
- 蓝色标题；
- 固定页边距。

## Skill 集成

LawFlow 同时提供独立 Skill，适合在支持 Codex Skill 的 Agent 中调用。

- Skill 目录：`skills/lawflow`
- 当前能力：读取项目上下文、生成大纲、保存宿主模型成稿、章节重做、章节导出、画像导入导出

如果你只想在本地 App 内使用，可以忽略 Skill；如果你希望把 LawFlow 作为 Agent 的专业工作台，也可以把 Skill 安装到宿主环境后调用。

## 当前边界

- 跨文档综合分析仍在继续完善，当前版本更适合单项目范围内的材料整理；
- 材料地图与候选核验项当前以规则和关键词为主，不等于严格语义审计；
- 长稿生成与音频合成目前仍是同步请求，尚未引入持久化任务队列；
- 写作画像作用于后续生成，已有成稿不会自动重写；
- 公开来源只有在用户明确导入后，才会进入讲稿生成范围。
