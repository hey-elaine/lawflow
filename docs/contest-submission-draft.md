# 律析 LawFlow：参赛提交草稿

> 供内部评审和演示准备使用。真实模型效果、节省时间和正式安装体验尚未测量，不应写成已验证成果。演示请使用公开材料或专门准备的脱敏材料。

## 1. 作品名称及简介

**律析 LawFlow——把长篇法律材料整理成可审阅的分章学习内容。**

LawFlow 是本地优先的法律材料学习与专业表达工作台。用户导入原始材料后，可选择目录范围，修改章节，再按写作风格、提炼或扩充程度和目标字数生成内容。成稿可人工审阅、按节修改并导出 Word；阅读进度在本机保存，音频是可选的后续步骤。

## 2. 应用场景与解决的问题

律师和法务常需在有限时间内阅读调研文档、法规、判决或实务笔记，再整理成专题学习内容或培训讲稿。原始材料篇幅长、结构不一致，直接交给模型处理容易忽略后半部分，也难以确认每一章依据了哪些材料。

LawFlow 让用户先限定学习范围、确认章节结构，再生成正文。每节保留材料块关联，便于检查内容与原文的关系。用户还可以逐份选择公开背景资料；未选资料不会自动进入写作内容。

## 3. 具体使用方式

1. 新建项目，选择专题学习、培训讲稿等场景，并决定是否需要音频。
2. 导入 DOCX、TXT、Markdown 或粘贴文本。长篇材料先从目录勾选要学习的章节。
3. 修改章节标题和顺序，确认写作范围；选择写作画像、提炼或扩充方式、目标字数，以及是否使用已导入的公开资料。
4. 检查大纲，按节生成内容。阅读时可标记已学并在下次继续；人工审阅后可修改、重做单节，并导出 Markdown 或 Word。
5. 如需碎片时间收听，再从已确认的内容生成口播脚本和音频。
