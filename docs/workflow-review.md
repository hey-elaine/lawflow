# LawFlow 工作流审查与优化

基线：`24fec465e2f1f01457e8c3a1acbb092a740bbfb9`。范围：后端、前端、数据库、生成与导出链路。未访问真实客户材料或调用用户付费模型服务。

## 已修复

| 问题 | 原因与影响 | 本次处理 |
|---|---|---|
| 音频机械、缺乏调节 | 系统浏览器语音或默认 `tts-1`，整篇一次发送，无节奏与音色比较入口 | 增加 MiniMax 原生适配、语速、兼容模型语气指令、可选口语润色、脚本编辑和短片试听；按句段拆分后用 FFmpeg 合并 |
| 音频时长不可信 | 通过字数估计，文件可能不是有效音频 | 完整合成使用 FFmpeg 解码及 ffprobe 读取实际时长；服务返回错误 JSON 不再写成 MP3 |
| 画像无法自定义 | 后端常量、前端硬编码四项，读取接口未使用 | SQLite 持久化新增/修改；前端动态选择；播客转写、风格提取、编辑确认、保存闭环 |
| 结构范围丢失 | “当前结构范围”只取第一个启用章节 | 合并所有启用章节，去重；没有匹配结构时明确提示，不偷偷切换到整篇 |
| 空范围变成全篇 | `read_blocks([])` 与未指定范围语义混淆 | 空列表返回空；确认结构要求至少一个有效启用章节 |
| 材料静默截断与错误回链 | 前端截前 120 块、后端截块文本/总预算；无效章节回链被自动替换 | 取消隐式截断，预算超限要求拆分；拒绝无效回链；确认大纲再次校验 |
| 短篇大纲偶发失败 | 提示词允许单节，校验却要求至少两节 | 精炼允许一节；将总目标时长换算为篇幅上限并分配到各节 |
| 正文含未填充的写作提示 | 将 opening_angle/closing_angle 直接拼接成正文 | 把思路交给首尾章节生成，正文只保留实际生成结果 |
| 讲稿无法完成审阅状态 | 前端只有保存修改，没有确认入口 | 增加确认审阅；有未保存正文时要求先保存；核验任务仍独立管理 |
| 脚本与音频不同步 | 修改来源与输出之间没有失效关系 | 编辑脚本使旧音频失效；源讲稿修改标记需更新；合成期间脚本变化拒绝写回 |
| 项目导出缺少主要交付 | 只读取 generated_contents，纯叙事项目无法导出 | 打包 narrative_contents、DOCX、口播脚本及已有音频，补充审计状态与章节回链 |
| 功能完成程度不透明 | 多源、外部核验、本地底稿和模型稿混在同一流程 | 展示真实计数、执行方式与未实现边界；“确认大纲”按钮不再暗示已开始生成 |

## 音频方案选择

建议优先用已接入的 MiniMax `speech-2.8-hd` 做中文播客候选，与现有服务使用相同 180 字样本对比，再决定是否切换。其原生接口提供音色、语速、情绪和停顿能力，本次先接入音色与语速，不自动插入笑声/喘息等表演标签。参考：[MiniMax 同步语音合成文档](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)。

ElevenLabs 可作为后续独立适配候选，官方接口提供 voice settings 和上下文参数；本次没有接入或宣称实测音质优于其他方案。参考：[ElevenLabs Create speech](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)。

验收建议：同一段法律术语、日期、金额、条件句和自然转场，检查读音准确性、句间停顿、音色稳定性和长稿接缝。不要仅凭“更像真人”忽略限定条件被错误断句。

## 后续优先级

1. **跨文档综合**：将单一 document_id 改为版本化来源集合，支持按文档展示实际选中范围和覆盖率；当前只是多文档归档。
2. **异步任务与恢复**：为逐节生成、ASR、TTS 建持久化 job/step 状态，支持进度、取消、幂等、失败重试和分段结果复用；避免刷新页面后不知是否完成。
3. **核验闭环**：区分规则提取候选、材料内部冲突、外部权威核验；补来源 URL、摘录、时效与处理结论。当前任务清单不能宣称已完成事实核验。
4. **来源与版本**：保存画像快照、正文版本、模型参数和提示词版本；将章节映射提升为主张级支持关系。范围变化后的核验任务也需要增量同步。
5. **服务工程化**：从单个 main.py 拆分 provider/audio/profile/workflow 模块，补并发任务控制与缓存清理；当前定位仍是本机工作台。

## 验证与边界

新增回归测试覆盖自定义画像持久化和进入提示词、提取草稿不自动保存、ASR 配置/同意检查与模拟转写、空范围与超限处理、大纲非法输入、写作提示不混入正文、试听不覆盖成品、音频失效、叙事成果包、MiniMax 请求结构和真实 FFmpeg 合并时长。

外部模型、ASR 和 TTS 使用模拟响应；FFmpeg 实际处理测试音频。没有使用真实服务密钥进行音质或端到端模型验收。
