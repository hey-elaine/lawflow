使用方式

从材料到成果，
按法律工作的节奏推进。

01

明确用途

先决定这份内容用于学习、培训、对外发言还是播客，系统带出合适的篇幅与审阅要求。

02

整理材料

导入一份法规、资讯、判决或实务笔记，确认需要使用的材料范围与内容主线。

03

确认事实边界

个人学习可以仅按原文整理；对外使用则先处理材料核对或发布前核验清单。

04

审阅并交付

形成可编辑讲稿、口播脚本和 DOCX；讲稿确认后，再生成正式音频。

审阅依据

每篇内容都有材料范围，
每个判断都保留确认空间。

限定材料范围

讲稿只使用选定材料能够支持的事实、规则和观点，不把材料外信息混入正文。

保留原文定位

审阅时可回看材料块、标题路径和来源链接，快速确认这段内容从哪里来。

把待确认内容留在核验清单

材料不足以支撑的判断不会伪装成结论；需要对外使用时，由律师完成发布前确认。

AI 协作

选择适合你的 AI 方式，
成果始终回到本地审阅。

检测本地服务中
A

使用自己的模型

连接 DeepSeek、OpenAI 或企业网关，在本地完成大纲、讲稿与 DOCX 导出。

适合需要批量处理或团队统一模型策略的场景。
B

使用本机 Agent

通过 Codex 或 CatPaw 读取受控材料块、生成内容并回写 LawFlow，继续审阅和导出。

无需在 LawFlow 中再配置额外模型 Key。
C

使用 ChatGPT Plus

复制当前材料包到 ChatGPT App 生成 Markdown，再粘贴回 LawFlow 审阅。

适合个人按需生成；不需要 OpenAI API 余额。
