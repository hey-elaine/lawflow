使用方式

三步，把「改天再看」
变成「今天读完」。

01

丢进来

公众号链接、网页、PDF、Word，或者一堆复制来的文字，都行。不用整理，丢进来就好。

02

拆成小课

AI 把长文拆成一节一节，每节一个主题，两三分钟能读完。拆得不合适？章节可以改。

03

碎片里学完

读，或者戴上耳机听。读完的打个勾，读到哪一节，它替你记着，下次接着来。

为什么可信

它不编，

它不编

每个说法都能回到原文那一段；材料里没有的，它不会悄悄补上自己的想象。

它记得

存疑的地方标得清清楚楚，你标记过「存疑」的表述，转译时会特意谨慎处理。

它在你电脑里

AI 协作

选择适合你的 AI 方式，

检测本地服务中
A

使用自己的模型

连接 DeepSeek、OpenAI 或企业网关，在本地完成大纲、讲稿与 DOCX 导出。

适合需要批量处理或团队统一模型策略的场景。
B

使用本机 Agent

通过 Codex 或 CatPaw 读取受控材料块、生成内容并回写 知了，继续审阅和导出。

无需在知了中再配置额外模型 Key。
C

使用 ChatGPT Plus

复制当前材料包到 ChatGPT App 生成 Markdown，再粘贴回知了审阅。

适合个人按需生成；不需要 OpenAI API 余额。
