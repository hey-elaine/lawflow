    使用方式

    三步，把「等有空再看」，
    变成「路上就听完」。

    01

    丢进来

    公众号链接、网页、PDF、Word，或者一堆复制来的文字，都行。不用整理，丢进来就好。

    02

    拆成小课

    四十分钟的长文，拆成四个十分钟。不用一次读完——今天一节，明天一节，剩下的留给去机场的路上。

    03

    带上路

    通勤、骑车、高铁驶进山区、飞机起飞以后——眼睛忙不过来，耳朵还空着。戴上耳机，听完今天这一节。

    为什么可信

    它不替你读书，
    只给阅读换一种发生的方式。

    它不编

    每个说法都能回到原文那一段；材料里没有的，它不会悄悄补上自己的想象。

    它记得

    存疑的地方标得清清楚楚，你标记过「存疑」的表述，转译时会特意谨慎处理。

    它在你电脑里

    材料、进度和学习记录都存在本地，不上传，不共享。

    我的书架

    把存下来的东西，再遇见一次。

    把链接、PDF 或长文丢进来，拆成一节一节的小课。支持公众号链接、网页、PDF、DOCX、TXT 和 Markdown。

    还没有项目

    收藏夹里第一篇没读完的，丢进来。

    AI 协作

    选择适合你的 AI 方式，
    成果始终回到本地审阅。

    检测本地服务中
    A

    使用自己的模型

    连接 DeepSeek、OpenAI 或企业网关，在本地完成大纲、讲稿与 DOCX 导出。

    适合需要批量处理或团队统一模型策略的场景。
    B

    使用本机 Agent

    通过 Codex 或 CatPaw 读取受控材料块、生成内容并回写声息，继续审阅和导出。

    无需在声息中再配置额外模型 Key。
    C

    使用 ChatGPT Plus

    复制当前材料包到 ChatGPT App 生成 Markdown，再粘贴回声息审阅。

    适合个人按需生成；不需要 OpenAI API 余额。
